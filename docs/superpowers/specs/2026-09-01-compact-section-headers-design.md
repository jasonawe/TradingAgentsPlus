# 紧凑栏目标题设计

## 目标

移除顶部导航已经表达过的页面级大标题，让用户进入页面后直接看到关注列表、分析表单、报告筛选、运行状态和报告内容。

## 信息层级

- `我的关注`、`分析任务`、`报告库`、`设置诊断`、`进行中`由顶部导航承担页面身份。
- 对应页面继续保留隐藏的 `h1`，供浏览器和辅助技术识别当前页面。
- `资产行情`、`分析参数`、`分析配置`、`行情来源`、`分析进度`、`过程记录`、`综合研判`等内容分组标题继续显示，但使用紧凑字号。
- 运行中的标的名称和报告名称继续显示，因为它们是当前对象而非重复页面标题；字号缩小为工作台层级。

## 操作布局

- `刷新行情`移动到资产行情工具栏，与自动刷新状态放在一起。
- `新建分析`保留在报告库顶部的紧凑操作栏。
- 返回、取消、下载等现有操作的位置和行为不变。

## 兼容性

- 不改路由、接口、数据结构或 JavaScript 状态流。
- 桌面和移动端都不留下空白标题占位。
- 隐藏标题使用通用视觉隐藏样式，不使用 `display:none`，确保语义仍可读取。

## 验收

- 五个主栏目不显示大型页面标题、眉标题和说明文案。
- 内容分组标题最大为紧凑工作台字号。
- 所有路由、操作按钮和内容区域继续存在且可用。
