# 投资评级中文显示设计

## 内部简报

- **用户：** 使用中文界面的个人投资者，能够理解常见投资概念，但不应被要求记忆英文评级术语。
- **任务：** 在分析完成、关注列表和报告浏览过程中，快速理解 `Underweight` 等模型评级，同时保留原始标准值供核对。
- **当前行为：** 部分入口直接显示英文，关注列表只翻译少量评级，导致同一结果在不同页面的表达不一致。
- **期望结果：** 中文界面的所有结构化评级统一显示为“中文（英文标准值）”；英文界面只显示英文标准值。
- **成功信号：** `Underweight` 在所有约定入口显示为“减持（Underweight）”，其他已知评级遵循同一规则，未知评级不会被误译或隐藏。
- **非目标：** 不改写数据库、API 返回值、模型输出和 Markdown 报告正文；不新增设置项或筛选规则。
- **对象：** 一次分析产生的结构化投资评级。
- **动作、范围与后果：** 只改变浏览器展示文本；历史数据、下载文件和后端解析保持不变，可随时回退。
- **权限：** 所有能够查看页面的用户都看到相同的本地化规则，不新增权限状态。
- **未决问题：** 无。

## 决策

采用单一前端格式化函数作为评级展示边界。它接收后端原始值，执行大小写和分隔符无关的匹配，再根据界面语言返回显示值。这样无需修改数据协议，也不会让不同页面各自维护一套翻译。该方案遵循 `rule/smallest-intervention`，并通过统一格式保留用户现有的数据心智模型（`rule/preserve-mental-model`）。

中文映射如下：

| 英文标准值 | 中文显示 |
| --- | --- |
| Strong Buy | 强烈买入（Strong Buy） |
| Buy | 买入（Buy） |
| Overweight | 超配（Overweight） |
| Hold | 持有（Hold） |
| Underweight | 减持（Underweight） |
| Sell | 卖出（Sell） |
| Strong Sell | 强烈卖出（Strong Sell） |

兼容 `StrongBuy`、`strong_buy`、`STRONG BUY` 等输入形式，并统一输出上表中的英文标准值。未知非空值原样显示，防止错误翻译；空值继续显示当前页面已有的完成/报告状态。已知、未知和空值均有明确回退，满足 `rule/cover-reachable-states`。

## 应用范围

格式化函数用于以下结构化评级入口：

1. 分析完成后的实时事件提示。
2. “我的关注”中最近一次分析评级。
3. 历史简报和报告库列表的评级。
4. 决策报告头部的“评级”元数据。

Markdown 报告正文仍按模型生成的原文渲染，避免对自然语言和代码块进行不可靠的字符串替换。下载的 Markdown 也保持原样。

## 状态与韧性

- 中文界面：已知评级显示双语，便于理解和核对。
- 英文界面：显示规范化英文，不插入中文。
- 未知评级：显示后端原值，不制造含义。
- 缺失评级：沿用页面现有状态文案。
- 长文本：本次不增加容器；沿用现有响应式换行能力。这是最小一致性改动（`rule/smallest-intervention`）。

## 验证

- 静态契约测试确认完整映射存在，且四个入口都调用统一格式化函数。
- JavaScript 语法检查确保浏览器脚本可加载。
- Web 静态测试与相关 API/历史测试确认没有破坏既有页面契约。
